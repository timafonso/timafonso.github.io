**Authors:** Álvaro F. Silva, Martim Afonso, Nuno Saavedra, Emily First, Alexandra Mendes, João F. Ferreira

Coding agents score well on existing Verus benchmarks, but those benchmarks supply the auxiliary lemmas a proof needs — something real projects do not. We introduce SeVerus, a technique that builds Verus benchmarks from the original proof dependencies of verified projects. Each verification target becomes a "quest" with progressively harder levels, created by removing proof context — from needing a single missing lemma up to proving the target with no supporting lemmas. An independent checker rejects changes to executable code, weakened specifications, and unsound proof constructs, while a noisy binary search estimates the highest level an agent can reliably solve. Applied to six open-source Verus projects, SeVerus generates 819 quests with 10,095 levels. Evaluations with Codex and Claude Code show that success falls and cost rises as context is removed: the strongest agent solves the final level of 52 of 60 sampled quests but reliably solves only 35% of their levels, with most failures on longer quests.
